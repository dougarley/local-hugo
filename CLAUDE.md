# local-hugo

Personal home media hub and guest-facing dashboard built with Hugo and Tailwind CSS v4.
Used as a central landing page for household and LAN party guests to access local
self-hosted services: games, media, photos, and shared files.

## Development

Run these two commands in separate terminals:

**Terminal 1 — Tailwind watcher:**
```bash
npx tailwindcss -i assets/css/input.css -o assets/css/output.css --watch
```

**Terminal 2 — Hugo server:**
```bash
hugo server --bind 0.0.0.0 --port 8181 --baseURL /
```

The site is served at `http://localhost:8181` and proxied through Nginx Proxy Manager
for guest/LAN access. Do not use `npm run build` for development — it runs Tailwind
once and exits.

## NAS Access

NAS connection details, SSH credentials, and internal service URLs are stored in `.claude-local.md` (gitignored — never committed). Check there for the SSH command, IP address, and ports for all running services including ROMM, Immich, Plex, etc.

## Environment Variables

Sensitive integration values are set via environment variables (not in `hugo.toml`).
Hugo reads `HUGO_PARAMS_*` automatically:

| Variable | Purpose |
|---|---|
| `HUGO_PARAMS_TUNARRURL` | Tunarr HLS channel player base URL |
| `HUGO_PARAMS_IMMICHURL` | Immich photo gallery base URL |
| `HUGO_PARAMS_IMMICHALBUM` | Immich album ID to display |
| `HUGO_PARAMS_IMMICHKEY` | Immich API key |

Never hardcode these values in `hugo.toml` or templates.

## Content Structure

Five sections under `content/`, each with an `_index.md`:

| Section | Purpose |
|---|---|
| `games/` | Modern games list for LAN parties — edited manually |
| `classic-games/` | Classic/retro games list — edited manually |
| `photos/` | Photo gallery via Immich integration |
| `local-tv/` | Local TV channels via Tunarr HLS player |
| `shared-files/` | NAS shared files browser |

## Styling

- Tailwind CSS v4 with a custom dark theme defined in `assets/css/input.css`
- Color tokens use the oklch color space — extend the palette there, not inline
- Red accent: `oklch(57.7% 0.245 27.325)`
- Dark surface stack: base → raised → overlay
- Text levels: primary, muted, faint
- `assets/css/output.css` is compiled — never edit it directly

## Do Not Edit

- `public/` — Hugo build output, fully regenerated on each build
- `assets/css/output.css` — compiled Tailwind output, regenerated by the watcher
